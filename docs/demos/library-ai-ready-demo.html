🤖 Making the Library App AI-Ready with SQL Server 2025

🎬 Scenario Introduction

I've been asked to add AI-powered semantic search to our existing Library app. The app is built with Node.js and Sequelize, but instead of modifying the ORM layer, I'll enhance the database directly using SQL Server 2025's new VECTOR capabilities.

In this demo, I'll show you how to make an existing app "AI-ready" by:

  • Using GitHub Copilot in VS Code to understand the schema and generate the SQL to add VECTOR support
  • Running Python scripts (already prepared) to generate and store embeddings
  • Demonstrating semantic search using SQL Server 2025's native vector similarity functions

"For this demo, I've already set up the environment — Python packages are installed, the .env file is configured with my SQL Server connection string, Ollama is running with the nomic-embed-text model, and the code is ready. Now let's focus on making the database AI-ready using Copilot."

Note: The books table uses lowercase column names (Sequelize conventions) and doesn't have a description column, so embeddings are generated from title + category.

🔹 Step 9: Understanding the Vector Search SQL

"So how does this actually work? Let me show you the SQL query that powers the vector similarity search. This demonstrates how SQL Server 2025's VECTOR_DISTANCE function compares book embeddings."

-- Vector similarity search query (768-dimensional vectors from Ollama)
-- This query finds books similar to a reference book by comparing their embeddings
DECLARE @ReferenceBookId INT = 9; -- "2001: A Space Odyssey"

SELECT TOP 3
    b.id,
    b.title,
    b.category,
    b.year,
    CAST(1 - VECTOR_DISTANCE('cosine', b.description_embedding, 
         (SELECT description_embedding FROM books WHERE id = @ReferenceBookId)) AS FLOAT) AS SimilarityScore
FROM books b
WHERE b.description_embedding IS NOT NULL
    AND b.id != @ReferenceBookId
ORDER BY VECTOR_DISTANCE('cosine', b.description_embedding, 
         (SELECT description_embedding FROM books WHERE id = @ReferenceBookId)) ASC;

"The VECTOR_DISTANCE function calculates the cosine similarity between a reference book's embedding and all other books' embeddings. It returns varying similarity scores based on semantic closeness. In our chat service, we generate the embedding from the user's natural language question and use that as the query vector instead. It's running entirely in SQL Server — no external vector database needed."
