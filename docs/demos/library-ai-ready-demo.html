🔹 Step 12: Understanding the Vector Search SQL

🎤 Voiceover: "So how does this actually work? Let me show you the SQL query that powers the vector similarity search. This demonstrates how SQL Server 2025's VECTOR_DISTANCE function compares book embeddings."

-- Vector similarity search query (768-dimensional vectors from Ollama)
-- This query finds books similar to a reference book by comparing their embeddings
DECLARE @ReferenceBookId INT = 9; -- "2001: A Space Odyssey"

SELECT TOP 3
    b.id,
    b.title,
    b.category,
    b.year,
    CAST(1 - VECTOR_DISTANCE('cosine', b.description_embedding,
         (SELECT description_embedding FROM books WHERE id = @ReferenceBookId)) AS FLOAT) AS SimilarityScore
FROM books b
WHERE b.description_embedding IS NOT NULL
    AND b.id != @ReferenceBookId
ORDER BY VECTOR_DISTANCE('cosine', b.description_embedding,
         (SELECT description_embedding FROM books WHERE id = @ReferenceBookId)) ASC;

🎤 Voiceover: "The VECTOR_DISTANCE function calculates the cosine similarity between a reference book's embedding and all other books' embeddings. It returns varying similarity scores based on semantic closeness. In our chat service, we generate the embedding from the user's natural language question and use that as the query vector instead. It's running entirely in SQL Server -- no external vector database needed."
