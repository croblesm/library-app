GitHub Copilot SQL + Sequelize Demo Prompts

🎬 Scenario Introduction

I was asked to implement a new feature in an existing Library management app built with Node.js and React. The app runs inside Dev Containers, which makes it quick to launch.

To begin, I explored the Express API, confirmed it's working with a call to GET http://localhost:3000/authors, and noted that the backend uses both raw SQL (T-SQL) and Sequelize ORM models for database operations.

As a developer, I’m comfortable working with ORMs — in past projects, I used Prisma, but this is my first time working with Sequelize. GitHub Copilot helps me ramp up faster by interpreting my SQL schema and suggesting Sequelize model code that matches the project’s conventions.

This demo walks through how GitHub Copilot can help me understand, extend, and reverse engineer the database schema — using natural prompts inside Visual Studio Code to work with both SQL directly and through Sequelize models.
